# laser-defender
A Galaga-inspired infinite scroller shooter where you kill as many enemy ships as you can before you die. In upright format because it was intended for mobile and features custom music written my me. Made with Unity and C# as part of a Udemy course. For Windows.

CONTROLS:
WASD to move
Left click to shoot

# INSTALLATION INSTRUCTIONS:
Download both zip files and just make sure to extract them in the same folder so the game has everything it needs. I had to do it in two zips because GitHub doesn't like big files.
